# 量化计算与数据契约 v1

日期：2026-09-17。状态：开发计划附件，待整体批准后实现。以下默认值属于本项目协议；不是行业统一标准，也不是已经通过测试的实现。

## 1. 时间、价格与样本

时间使用 Asia/Shanghai 交易日历，日期是交易日，不按自然日或单证券非空行计数。t 表示信号交易日；O_i(t) 表示证券 i 在 t 日的研究开盘价。原始行情、研究价量和估值视图分开存储。

信号在 t 收盘后形成；理论调仓发生于 t+1 开盘。预测标签定义为：

`y_h(t,i) = O_i(t+1+h) / O_i(t+1) - 1`，`h ∈ {1,5,10,20}`。

因此 h=1 是下一开盘到再下一开盘的收益。标签允许读取未来，特征不允许。一个 5 日标签不是五个互相独立的单日收益；分组的重叠多日标签不能直接连乘生成真实资金净值。

信号日期、标签起止日期、调仓日期、收益区间和最终估值日期分别保存在产物中。界面不能只显示一个含糊的 date。

默认研究区间 2021—2025；训练 2021—2023，验证 2024，最终测试 2025。每段只保留标签终点仍在该段内的训练或评价样本；末尾不足 h+1 个交易日的信号作截尾处理并计数。后续缓冲数据可以下载，但不得悄悄进入前一段的评价。

## 2. 标准数据与快照

### 2.1 必要字段

| 字段 | 含义与约束 |
| --- | --- |
| instrument / exchange | 明确交易所的统一证券代码，原始代码另存 |
| trade_date / calendar_id | 交易日期与日历版本，保持完整交易日轴 |
| open/high/low/close_raw | 原始未复权价格，人民币/股；合法交易时大于 0 |
| volume_raw | 成交股数，明确由“手”到“股”的转换，不能默认单位 |
| amount_raw | 成交额，人民币元；保存供应商原始单位及转换规则 |
| adjustment_factor | 相对于原始价格的研究调整比例，保留供应商原始因子与转换依据 |
| open/high/low/close_research | 用于一致收益计算的复权价格视图 |
| trade_status / quality_flags | 正常、已确认停牌、未知缺失、异常等；未知不等于正常 |
| source / retrieved_at / snapshot_id | 来源、抓取时间、快照版本 |

原始 OHLC 顺序、价格范围、重复记录、零/负成交量、价格跳变、缺日和单位转换均做检查。确切停牌标志、ST 标志、上市/退市日期等可作为扩展字段；缺失时不得使用当前状态回填历史。

### 2.2 Qlib 研究视图

保存价格因子 F，使 `price_qlib = price_raw × F`；采用对应的 `volume_qlib = volume_raw / F`。归一化基准与复权方法固定在快照中，不随查询日期重新选择。

VWAP 在 `volume_raw > 0` 且单位校验通过时用 `amount_raw / volume_raw` 派生，再乘相同价格因子。零成交量时 VWAP 为缺失，不取 OHLC 均值，不自动除以极小值造出价格。

Qlib 视图提供 `$open/$high/$low/$close/$volume/$vwap`，平台可扩展 `$amount` 等声明过的字段。真实成交股数和金额保留在标准层，不能用调整后的 volume 解释真实交易容量。

数据转换验收包含价格和成交量可逆还原、价格×量的一致性、除权附近检查、供应商复权对照。供应商的复权价格收益是本项目的研究收益代理；首版不建立独立分红、送股和现金到账账本，也不将其宣称为精确总收益账户。

### 2.3 缺失与停牌

- 特征输入保持完整日历轴；已确认停牌的价量输入设为缺失，不删除该日来缩短窗口。
- 估值视图可以对已确认停牌沿用最后有效研究价格，记录估值来源。复牌后收益相对于最后估值计算。
- 若调仓时当前持仓或拟买目标涉及已确认停牌/无可用交易价格，整次调仓跳过，原持仓继续估值，成本为 0；下个计划调仓日再尝试，不临时选取另一批赢家。
- 未确认原因的持仓估值缺失、价格异常或无可靠退市估值，阻止该次回测标为完整有效；给出证券和日期。不得把股票免费移出组合，也不得填零收益掩盖缺失。
- 样本尾端标签不足只影响对应预测评价行，不能据未来标签是否存在来提前筛掉回测股票。
- 合成样本与真实行情有不同标识；合成样本验证计算，不用于报告历史投资表现。

## 3. 因子、表达式与自定义函数

### 3.1 因子版本

每个版本包含 factor_id、version、expression 或 plugin_ref、source_hash、参数、字段依赖、lookback、输出单位/说明、方向 sign∈{+1,-1}、作者说明和注册时间。修改任何影响输出的内容生成新版本。

Python 时序算子接收单证券序列；面板因子接收日期×证券数据并输出同样对齐的单列分数。自定义函数不能重排或丢失键而不声明；重复键、额外未来行和不匹配形状视为错误。

函数库分为内置 Qlib 算子、自定义时序算子、自定义截面/面板函数。自定义名称禁止覆盖内置；依赖其他插件时保存完整版本闭包。

### 3.2 Qlib 兼容清单

首版保留原 Qlib 语义，不把 `Rank` 改写成截面排名。基础能力包括字段引用、数值字面量、算术、布尔比较、括号及经允许的函数调用。

核心验收算子包括 `Ref, Mean, Std, Slope, Rsquare, Resi, Max, Min, Quantile, Rank, IdxMax, IdxMin, Corr, Log, Sum, Abs, Greater, Less` 及所需基础比较运算。`Greater/Less` 按 Qlib 逐元素最大/最小语义处理，不能误当布尔比较。

使用固定版本 Qlib 生成的全部默认 Alpha158 表达式作对照：9 个 Kbar 特征、4 个当日价格特征、29 类×5 个窗口滚动特征；需要 VWAP。锁定版本后重新提取清单，不手抄一个未经核对的“158”列表。

首版首先保证有限正窗口。`Ref(x,0)` 引用载入序列首值，不等于 x；零窗口 expanding、EMA 初始化及未声明窗口的插件列为待专项支持，未通过测试时明确拒绝。此约束必须在导入结果中逐条显示，而不是静默跳过公式。

### 3.3 防止未来信息进入特征

- 导入表达式先解析语法，拒绝任意属性访问、导入、文件/网络调用和未注册名称，再传给 Qlib。不能直接对未校验文本执行 Python eval。
- 特征禁止负偏移 Ref/Delta 以及其他直接或嵌套未来引用；对每个算子检查真实依赖，不仅依赖一个窗口元数据函数。
- 自定义函数声明回看窗口和数据可用时点，执行“截断数据与追加未来数据后，既有日期结果一致”测试。
- 归一化和预处理遵循相同数据时间边界；跨日期拟合只能使用训练区间。
- Qlib 兼容输出可能为 float32；统计与资产计算统一提升为 float64。兼容比对采用预先定义容差，NaN 掩码单独逐项比对。

## 4. 截面处理与股票选择

默认每天以该日已经可知的股票池和有限因子值为截面；不依据未来收益缺失、未来停牌或未来涨跌幅筛选。

单因子报告同时保存原始与处理后值。用于组合及模型的默认处理是每个截面按 1%/99% 分位裁剪，再做均值/标准差标准化；标准差使用 ddof=0。所有处理参数和所用股票集保存。零方差列输出 0 并标记常数，原始 IC 不因此伪造为 0。

模型比较使用同一完整特征掩码，不为不同模型悄悄填补不同的样本。缺少任一必需特征的证券当天不产生该实验分数。单因子分析可以使用其自己的有效截面，并报告数量。

默认至少 20 个有效证券才形成一个有效截面；不足则报告样本不足。因子值全部相同的截面不提供有意义的分组或排名策略。不同值较少/并列过多时显示提示。

5 组按分数排序，边界并列使用证券代码稳定排序，分组人数相差最多 1。实现保证最高组人数为 `ceil(0.2×N)`，选股参考组合与最高组采用相同的排名边界。排名相关使用并列平均秩，不能用稳定排序的任意打破并列替代统计秩。

组合方向为预先配置的 sign；不能根据最终测试收益自动翻转。等权模型使用同一特征集合的带方向标准化值平均；学习模型输出预测收益供排序使用。

组合默认投资比例为 100%，按前 20% 等权；可配置比例在 [0,1]，剩余现金收益为 0。预测分数为负不自动意味着清仓，因为默认策略是截面排序。无有效目标且可正常估值时持现金；已有持仓遇到异常按第 2.3 节处理。

## 5. 权重、换手与资金守恒

### 5.1 调仓前权重

设第 k 个收益区间开始时，扣费后股票权重为 w_i,k，现金权重为 w_c,k；区间股票收益为 r_i,k，则毛组合收益：

`R_g,k = Σ_i w_i,k × r_i,k`。

下一个开盘调仓前，权重为：

`p_i,k+1 = w_i,k × (1+r_i,k) / (1+R_g,k)`；

`p_c,k+1 = w_c,k / (1+R_g,k)`。

非调仓日继续持有漂移后的权重，不强行恢复等权。每日调仓与每 5 个交易日调仓以该运行的第一个有效调仓日为起点，按全市场交易日索引计数。

### 5.2 成本方程

设调仓前资产 V，股票权重 p_i，新目标为相对扣费后资产的 w_i，买卖费率分别为 c_b、c_s；默认都是 0.001。求扣费后资产比例 λ：

`λ = 1 - c_b Σ max(λw_i-p_i,0) - c_s Σ max(p_i-λw_i,0)`。

合法输入要求 `0≤c_b,c_s<1`、股票和现金权重非负、股票权重之和不超过 1。此条件下方程在 `(0,1]` 存在唯一解；用有界求解获得 λ。验收要求方程残差与资产守恒误差达到规定容差。这是权重层的成本核算，不生成订单或逐笔成交。

买入规模 `B = V Σ max(λw_i-p_i,0)`；卖出规模 `S = V Σ max(p_i-λw_i,0)`；费用 `C=c_bB+c_sS`；扣费后资产 `V⁺=λV`。

扣费后股票名义金额为 `V⁺w_i`，现金为 `V⁺(1-Σw_i)`，因此不会因满仓再扣费而制造负现金。

本区间净增长：`V_next = V × λ × (1+R_g)`；净收益 `R_net=λ(1+R_g)-1`。

非调仓日或跳过调仓时 λ=1。首次建仓从全现金开始；终点只估值，不生成零持有期调仓或强制平仓。毛收益曲线来自同一策略、零成本情景的独立资金递推。

### 5.3 换手命名

- **双边资金换手** `T=(B+S)/V`，现金不作为另一条交易重复计数。
- **半双边换手** `T_half=T/2`，仅作为显式命名的辅助口径。
- **平均日换手** 对完整回测收益区间平均，非调仓日为 0；另显示每次调仓平均值。
- **分组成员换手** 对指定间隔 Δ，`|Q_t \ Q_(t-Δ)| / |Q_t|`；组为空或历史不足时为缺失。
- **排序自相关** 对两个日期共同有效的股票，计算截面平均秩的相关性；它不是资金换手。

所有资金换手均标注“理论权重模型估计”。成本敏感性情景中，双边费率分别取 0、0.0005、0.001、0.002。

### 5.4 手算基准

- 零成本：50% A、50% B，A 涨 10%、B 不变，则资产增长 5%；下期权重为 52.38095238% / 47.61904762%。恢复等权时双边换手为 4.76190476%，不是 0。
- 全现金建仓一只股票，费率 0.001：`λ=1/1.001=0.999000999…`。若价格不变，净值即该值；费用按扣费后实际投入规模计算。
- 随后完全清仓，费率 0.001：总净值为 `(1-0.001)/(1+0.001)=0.998001998…`。默认期末不清仓，所以此例只用于明确清仓情景测试。

## 6. 指标定义

指标保存 metric_id、definition_version、period、样本数、单位、方向、费用配置和数据状态。不可计算时返回 null 与原因，不返回具有误导性的 0 或 Infinity。

| 指标 | v1 计算口径 |
| --- | --- |
| Pearson IC | 每日因子值与对应 h 日标签，在共同有效证券上的 Pearson 相关 |
| Rank IC | 同一截面上的 Spearman 相关，使用平均秩处理并列 |
| ICIR / Rank ICIR | 对每日 IC 序列计算均值/样本标准差（ddof=1），默认不年化，分别命名 |
| 正 IC 比例 | IC>0 的有效日期数 / IC 有效日期数；0 不计为正 |
| 分组标签收益 | 先按信号日分组，再对各组可观测标签求均值，保留每组有效数 |
| 最高减最低组 | 同一日期、同一 h 的两组标签均值之差；是诊断序列，不宣称为可执行做空净值 |
| 分组单调性 | 每日组序号与组均值的 Spearman 相关，以及全期各组均值曲线 |
| 总收益 | 最终 NAV / 初始 NAV - 1，初始 NAV 包含建仓前现金基准 |
| 年化收益 | `(NAV_end/NAV_start)^(252/n)-1`，n 为实际核算的交易日收益区间数 |
| 年化波动 | 单日收益样本标准差 × sqrt(252) |
| Sharpe | 单日超额无风险收益均值/样本标准差 × sqrt(252)，默认无风险收益 0 |
| 最大回撤 | `max(1-NAV_t/running_max_NAV_t)`，含初始现金 NAV |
| Calmar | 年化收益/最大回撤；最大回撤为 0 时缺失 |
| 正收益日比例 | 日净收益>0 的日期数/有效收益区间数，含零收益日作为非胜日 |
| 基准超额曲线 | 同起点归一化的 `NAV_strategy/NAV_benchmark - 1` |
| 信息比率 IR | 单日策略收益减基准收益的均值/样本标准差 × sqrt(252)，与 ICIR 分开 |
| 单位成交额收益 | 同一成本情景的总 PnL/累计理论成交金额；PnL 包含末期未实现盈亏；成交额为 0 时缺失 |

年化常数默认 252，并记入 provenance；程序接口可用 `annualization` 设置 1—366 的整数，界面默认保持 252。换年、半年度和短样本不更改同一实验的口径。年度结果显示各年度的非年化实际收益，同时全期给年化指标。

分组标签收益与 IC 存在多日重叠，v1 不提供默认独立同分布假设下的显著性星号或年化 ICIR。稳健显著性、区块自助法和多重试验修正列为后续能力。

预测指标的样本对齐逐周期记录；比较两因子时采用相同股票/日期交集并报告有效覆盖。因子值相关按截面计算后汇总；参考组合相关基于同成本情景、同日期的单日收益。加入/删除因子的增量收益须重新训练（若适用）与重新回测，不直接加总单因子 PnL。

## 7. 基准与报告范围

沪深 300 默认采用可验证来源的价格指数开盘序列，作为市场参照；如未取得所需开盘数据，报告该基准缺失，不用收盘序列静默替换。将来接入全收益指数时建立新的 benchmark_id。

股票池等权基准采用与策略相同股票池、价格视图、可用性规则和调仓周期，默认全池等权；提供与策略同费用的可比曲线及无费用参照。存在停牌导致的跳过调仓时单独记录。

股票复权代理与市场价格指数有分红口径差异；主要公平比较使用同池等权基准。缺市场基准时仍可计算绝对指标，但相对该基准的指标必须为缺失。

报告显示实际信号区间、收益区间、有效股票数、预热/截尾损失、未知缺失、跳过调仓次数、复权方式、样本池偏差、模型/代码/数据版本及全部费用假设。

## 8. 模型、时间切分与复现

特征序列允许使用段起点之前的已知历史预热；标签必须在所属段内完全结束。训练结束时尚未实现的收益标签不进入训练。验证和最终测试按相同原则隔离，不随机打散时间。

每次实验固定 FeatureSet、LabelSpec、SplitSpec、UniverseVersion、DataSnapshot、CostSpec 和 PortfolioSpec。三模型使用同一可比面板；等权基线同样应用该面板掩码。

跨时间学习的参数只由训练段确定；纯截面标准化只使用当日已经可知的数据。标签不按全样本分布过滤异常值；可核实的数据错误在快照质量层处理，修复后生成新版本。

ModelAdapter 契约包含参数描述、fit(train)、predict(features)、save、load、metadata；标签与未来列不传入 predict 的特征对象。首版固定训练一次，保留 fold_id 字段为下一版滚动实验使用。

默认种子固定并记录，CPU 线程数记录。缓存键至少包含输入内容哈希、表达式/插件代码、参数、预处理、日历、库版本与归一化基准；仅修改成本时可复用原始因子和预测分数，但必须重新产生对应回测结果。

同一环境重复运行按验收容差比较；保存代码副本、依赖清单和机器信息。外部数据被修订后，只能生成新实验，不能覆盖旧实验以制造“完全复现”。

## 9. 参考实现与独立验证

Alphalens 用于对照 Rank IC、分组与成员稳定性等定义；其 API 中未来收益异常值过滤显式关闭。项目自己的时间对齐、权重收益、费用和基准由本契约控制。

Qlib 用于公式语义和可扩展计算接口。其窗口元数据不能独自证明无未来依赖，必须配合公式审查和时序不变性测试。

数值正确性使用手工小样例、独立公式、上游接口比对和特定不变量共同验证；不把“同一份实现运行两次结果相同”当成正确性的唯一证据。

参考：[Qlib 数据约定](https://qlib.readthedocs.io/en/latest/component/data.html)、[表达式源码](https://github.com/microsoft/qlib/blob/main/qlib/data/ops.py)、[Alpha158 定义](https://github.com/microsoft/qlib/blob/main/qlib/contrib/data/loader.py)、[Alphalens API](https://alphalens.ml4trading.io/api-reference.html)。本项目的费用、日期、分组和缺失政策属于明确提出的设计选择。
