## 2. 数学与隔离检查

代码与已有测试支持以下判断，尚未据此替代全规模端到端验收：

- 标签为下一开盘至 `h` 个交易日后的开盘，训练/验证/测试评价限制标签终点不越过所属区间。
- 三种模型在相同完整特征面板上预处理；预测掩码独立于未来标签可用性，尾端无标签仍可生成当期预测。
- 预处理为当日截面操作，训练模型只使用训练评价掩码；预测时检查特征列名、顺序和有限值，未把目标收益传给 predict。
- 成本按资金守恒方程求解，计入首次建仓，不重复计算现金交易；非调仓日权重漂移；终点不生成零持有期新调仓。
- 测试已有手算漂移、建仓/清仓成本、随机权重资金守恒、标签时点、分组并列、停牌、模型保存/加载和同环境重复预测检查。

当前 Qlib 表达式/数据集磁盘缓存显式关闭，存在的是每个快照的 Qlib 衍生文件视图。不能把现状描述为已完成包含模型和预测的全面缓存系统。

## 4. 后端审查修复

本审查者已在后端实现并添加回归测试：

| 边界 | 实现 |
| --- | --- |
| 多实例与重启 | 工作区独占文件锁；只有本实例恢复任务。重启把未确认完成的 RUNNING 标为 INTERRUPTED，保留 QUEUED。 |
| 不可变版本 | 修订已有 id 时产生新 id、递增版本并保留逻辑实体；未知旧 id 不会静默变成新实体。 |
| 输入冻结 | DATA_IMPORT 在入队前复制源文件到工作区并记哈希，排队期间修改原文件不会改变任务输入。 |
| 取消竞态 | 已终结的成功任务不被晚到取消覆盖，不发布错误的取消状态。 |
| 结果登记 | 成功退出不足以标为成功；检查结果 schema、有限数值、必需字段、产物存在性和路径范围。非零退出/缺结果保留失败状态。 |
| 文件访问 | 输入限项目/工作区；只下载登记产物，核验大小/哈希；拒绝路径穿越、绝对产物路径和逃逸符号链接。 |
| 导出与重跑 | 导出只接受成功且未改写的源结果；重跑自动引用旧运行的冻结插件路径。 |

## 5. 最终测试访问审计

SQLite V2 新增独立 `job_report_access` 表。成功 `MODEL_EXPERIMENT` 的结果 API 请求，包含自动抓取和 API 工具读取，都算一次暴露，记录：

- `testViewedAt`：首次记录的结果 API 访问时间。
- `lastViewedAt`：最近记录的结果 API 访问时间。
- `testViewCount`：已记录访问次数。
- `testViewAuditStatus`：`NOT_VIEWED`、`VIEWED`、`UNTRACKED_HISTORY` 或非模型任务的 `NOT_APPLICABLE`。
- `testViewHistoryKnown`：该任务是否在审计启用之后创建。

这些字段通过 job 与 bootstrap 返回，不写回原始 `result.json`，不改变报告产物哈希。单纯内部结果校验不算外部访问；本次审计范围是结果 API，不包含直接文件系统读取或仅下载产物。

GET 结果入口已复核：在返回模型结果前，以单条 SQLite UPSERT 保留首次时间并递增次数；API 响应设置 no-store。记录代表服务端结果访问，不声称证明人已经阅读；自动读取同样记账。成功结果不可变，读接口不重写报告，未发现当前约定范围内的遗漏入口。

V2 之前任务的历史访问无法重建，因此缺少记录时显示 `UNTRACKED_HISTORY`，不能称作“从未查看”。首次新记录之后可确认已经暴露，但历史完整性仍为 false。数据库迁移使用 SQLite `VACUUM INTO` 创建包含已提交 WAL 数据的备份，再执行事务化迁移。

新增测试覆盖首次访问保持不变、最近访问推进、访问计数、非模型/失败任务不计数、重启后审计保留、bootstrap 字段、V1 数据保留、历史未知标识，以及原始结果文件哈希和数据库结果内容不变。2026-09-17 16:04 的离线 `mvn test` 实测共 20 项，通过 20 项，失败/错误/跳过均为 0。8080 由集成负责人统一重启，本审查不重启正在运行的服务。
