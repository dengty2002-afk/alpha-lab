## 明确限制

当前成果是单机可行性验证版本。使用固定样本，历史退市覆盖未证明；复权研究价格不是独立分红现金账本；股票复权代理与沪深300价格指数有分红口径差异。没有撮合、涨跌停成交、整手或容量模拟。

AKShare 作为备用适配器已实现，本次实证闭环使用 BaoStock。代码、插件与依赖可以归档恢复，未承诺在任意新依赖版本或另一操作系统上逐位复现。缓存仅包含经校验的 Qlib 派生视图，没有模型/预测的通用缓存系统。

下一版重点为滚动训练、逐折标签隔离和连续样本外预测。首版不包含自动搜参、GPU 管理、财务/PIT 因子或真实交易。
