# 使用指南

## 第一次运行

在项目目录执行 `scripts/start.ps1`，浏览器打开 `http://127.0.0.1:8080`。首次准备环境参见根目录 README。服务与研究进程都在本机运行，SQLite 无需单独安装服务。

数据页中的真实快照可直接使用。开发验证取得了 BaoStock 98 只证券、2021—2025 研究区间及前后缓冲的行情；目标池中 `sz.000002` 与 `sz.000063` 因网络接收错误未取得。具体内容以所选快照的 manifest 为准，重新下载会生成另一份不可变快照。

如果自己下载，先选择股票池/代码、日期和来源。完整下载耗时取决于外网服务；可以在任务页查看逐证券进度。下载失败会展示错误。合成样本有单独入口和明显标识，只验证软件计算。

## 从一个因子开始

1. 在因子库选择“20 日动量”等已有公式，或者新建 `$close / Ref($close, 20) - 1`。
2. 为定义取名，选择方向。方向 `1` 表示买高值，`-1` 表示买低值；修改后形成新版本。
3. 选择数据快照和日期，先预览有效值与缺失。量价字段来自复权研究视图，原始成交量以股计、成交额以元计。
4. 在单因子分析运行报告。默认看 1/5/10/20 日标签、5 组、每日和每 5 日调仓，以及 0/5/10/20 bps 成本。

IC/Rank IC 判断因子与未来收益的线性/秩关系；ICIR 是每日 IC 均值除以标准差，未年化。正 IC 比例、有效覆盖、分组收益与单调性一起看，避免只挑一个指标。分组多日平均收益描述预测能力，不能把重叠标签连乘成账户净值。

排名自相关反映分数排序持续性；成员换手反映分组股票变化；资金换手来自漂移后的持仓变化，含初次买入。三者意义不同。Sharpe、最大回撤与成本敏感性来自理论组合逐日收益。

原始 IC 保留原始因子的符号，组合和分组按所选方向排序。样本不足、常数截面或零方差时显示缺失值，而非无穷大。

## 三模型实验

选择一组因子、同一快照与标签，设置训练/验证/测试区间。默认训练 2021—2023、验证 2024、测试 2025。等权评分、Ridge、LightGBM 使用相同完整特征行及同一收益口径。

训练样本的标签终点不得越过训练结束日期；报告给出剔除数量。预处理只使用信号当日截面。预测所需证券不会根据未来标签是否存在来筛选。

先利用研究与验证区间调整参数。查看最终测试后再依据其结果挑模型，会使该段不再是未见过的最终测试；平台保留运行记录，不能从统计上消除这种选择偏差。首版固定切分，滚动训练列入下一版。

修改参数、增加/删除因子后创建新实验，比较时核对快照、标签、切分、成本、调仓周期及特征共同样本。因子相关性只是互补性线索，增量贡献应通过重新训练和回测判断。

## 结果与复现

任务成功后才开放报告和产物。可下载自包含 HTML、JSON、CSV/Parquet 明细、模型、因子定义、provenance 和研究源码归档。HTML 可离线打开；CSV 的原始数值用于自行复算。

同参数重跑应引用相同快照和被冻结的插件。环境/研究核心代码也有版本哈希及源码归档；跨环境复现应恢复对应归档与依赖锁，不应直接把升级后的引擎结果叫作旧代码重跑。

首版报告是研究用理论权重结果。固定股票池未证明覆盖历史退市股票；未知持仓缺价阻止完整回测；已确认停牌采用前值估值并跳过相关整次调仓。未模拟涨跌停成交、整手、容量或真实分红现金账本。
